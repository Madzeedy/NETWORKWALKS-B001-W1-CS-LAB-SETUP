# NETWORKWALKS-B084-W1-CS-LAB-SETUP
CS-LAB-SETUP – Building an Isolated Virtual Lab for Penetration Testing and Ethical Hacking


This project involves building a virtual cybersecurity lab using VirtualBox and Kali Linux to practice penetration testing and ethical hacking in a controlled environment.

The lab provides a safe space to practice network scanning, reconnaissance, vulnerability assessment, and other security-testing techniques using cybersecurity tools.

It is designed around a private virtual network, allowing additional virtual machines to be added as targets for authorized security testing as the lab develops.
